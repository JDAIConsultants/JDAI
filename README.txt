How to upload to Cloudflare Pages
1. Log into Cloudflare.
2. Go to Pages.
3. Choose Create application or Create project.
4. Choose Direct Upload.
5. Upload the entire folder or a zip containing these files.
6. Set index.html as the default entry file if asked.
7. Publish.

Important
- This is a static site. No build step is required.
- The demo intake form on contact.html does not submit yet.
- For a live form, connect to a form backend later or use email / scheduling links.
